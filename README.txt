SCHOLARBUDDY - WEB TỔNG HỢP HỌC BỔNG
1. Cài Node.js (https://nodejs.org). Bấm đúp start.bat (hoặc chạy: node server.js).
2. Người dùng: http://localhost:3000   |   Quản trị: http://localhost:3000/admin
3. Link công khai (cần chạy thêm start-tunnel.bat): https://unfair-motivator-galleria.ngrok-free.dev
Mật khẩu quản trị đặt trong start.bat (dòng ADMIN_PASSWORD).
Dữ liệu: data/scholarships.json (học bổng mẫu), data/reviews.json (đánh giá mẫu để thử).
Trang chủ hiện 3 học bổng có nhiều lượt xem chi tiết nhất (data/views.json, đang là số mẫu - xóa file này để đếm lại từ 0). Mỗi lần có người bấm xem chi tiết một học bổng là cộng 1 lượt.
Ảnh minh họa: mỗi học bổng có ô "Link ảnh minh họa" trong trang quản trị; để trống thì dùng biểu tượng mặc định.
